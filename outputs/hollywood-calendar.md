**Sourcing rule:** Every date below is pulled from an official event organizer site, official press release, or confirmed trade press reporting on an official announcement. Nothing is estimated. ## How other agents should use this file
- `market-signal-researcher` reads this file for timing context and should not re-derive dates.
- `social-content-engine` reads this file plus `outputs/media-contacts-map.md` to build its posting calendar.
- Handoff is manual — reference the file path directly, nothing chains automatically (see `runbook.md`).

## Legend
- **CONFIRMED** = exact date verified via official source or confirmed trade press
- **EXPECTED — UNCONFIRMED** = event is known to recur but 2026/2027 date not yet public
- **Access route** = how a boutique agency could realistically get a client into the room (press credential, brand partnership, gifting suite application, direct event invite, industry guild membership required, etc.)
- **Hook required** = the news angle a client needs to justify pitching them for the booking
