# Placement Pattern Library

**Method note:** this file tracks *beat patterns* — which outlets and desks reliably cover which
kinds of stories — reverse-engineered from published coverage. It does not assert or imply that
any named journalist has an improper or exclusive relationship with any publicist; that would be
an unverifiable claim about a private professional relationship, not something this agent can
confirm from public information, and asserting it would violate the "never invent" constraint.
What's genuinely findable and useful is coverage-pattern mapping: who covers what, how often, and
what kind of story gets picked up where.

**First pass, August 16, 2026 — this library is essentially unseeded.** One general search for
gospel/R&B legacy-artist beat reporters at Variety, THR, and Page Six returned mostly artist "to
watch" list content, not identifiable recurring bylines on this specific beat. That's a real,
honest result, not a failed search — it suggests legacy gospel/R&B coverage at the majors is
assigned more ad hoc than as a dedicated beat, which is itself a useful finding.

## What this means for the founder
Do not expect this file to be a mature "who places with whom" map yet — it isn't, honestly. The
real, current beat pattern found in this pass: outlets like EURweb (per `media-desk`'s earlier
research) run dedicated gospel sections with a recurring editorial slot, which is a stronger,
more findable pattern than trying to track individual trade-press bylines. Future passes should
build outward from outlets with dedicated recurring sections/franchises (like EURweb's Gospel
section, or Variety's "___ to Watch" annual franchises, already noted in
`outputs/market-signals.md`) rather than trying to reverse-engineer individual journalist
relationships from scratch.
