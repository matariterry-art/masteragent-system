# Distribution Lists

Not yet built. This folder is meant to hold the clean, curated, mail-merge-ready export actually
used for outreach — organized by market and genre — pulled from verified entries in
`spotlight-database.xlsx`.

This first pass (August 16, 2026) focused on Los Angeles newsroom/route mapping and produced only
a handful of verified entries — not yet enough curated, confirmed contacts to justify a real
distribution export. Building this out is a next-pass task, once `spotlight-database.xlsx` has
enough verified, current entries in a given market/genre to make a curated export meaningful
rather than premature.
