# Market Rate Intelligence

What comparable artists command in each lane, where public — so the firm negotiates from data,
not instinct. **Sourcing honesty, up front:** almost all of this comes from booking-agency
marketing pages (companies that sell talent-booking services), not verified transaction records or
a party to an actual deal. Treat every figure as directional market context, not a confirmed rate
— mark accordingly, and re-verify before using a number in an actual fee conversation.

**Created:** August 16, 2026, during global-spotlight's first run under the in-house booking
operation upgrade.

## Live performance — R&B/soul/legacy artist category

| Tier | Range | Source | Confidence |
|---|---|---|---|
| General soul singer, solo or small band, local event | ~$120 (solo w/ backing tracks) to $1,400+ (full band) | Seattle Talent Buying / aggregator rate guide | 🔴 Unverified — marketing-page estimate, wide range |
| Typical booking, general soul category | ~$410 | Same source | 🔴 Unverified |
| Classic R&B / soul / disco / funk, named-artist tier | $7,500 up to $1,000,000+ depending on prominence | Booking Entertainment (agency marketing page) | 🔴 Unverified — extremely wide range, not artist-specific |
| Adult Contemporary legacy acts | $350,000 – $750,000 | Aggregator rate guide | 🔴 Unverified |

**What this means for Freda specifically:** this range is far too wide to be useful as-is —
$7,500 and $750,000 are not the same negotiation. **Do not quote any of these figures externally.**
The realistic approach: let festival/venue programmers name their budget first where possible
(standard practice per the booking-mechanics research above), and treat this table as background
context for internally sanity-checking an offer, not a number to lead with.
